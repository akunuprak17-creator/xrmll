02Latar Belakang

Latar Belakang

1

Masalah

Pakaian yang dijemur di luar sering basah kembali karena hujan turun tiba-tiba saat penghuni rumah sedang beraktivitas di luar.

2

Kebutuhan

Diperlukan sistem yang dapat mendeteksi hujan secara otomatis tanpa harus menunggu manusia mengangkat jemuran secara manual.

3

Solusi

Arduino dipadukan dengan sensor hujan dan motor servo untuk menarik jemuran masuk secara otomatis ketika hujan terdeteksi.

04Cara Kerja Alat

Cara Kerja Alat

1

Deteksi Hujan

Sensor hujan mendeteksi tetesan air di permukaannya dan mengirim perubahan nilai resistansi ke Arduino.

▸
2

Pemrosesan Sinyal

Arduino membaca nilai sensor. Jika melewati ambang batas tertentu, sistem menyimpulkan hujan sedang turun.

▸
3

Penggerak Motor

Arduino mengirim perintah ke motor servo untuk menggerakkan mekanisme penarik tiang jemuran.

▸
4

Jemuran Masuk Otomatis

Tiang jemuran bergerak masuk ke area terlindung sehingga pakaian tidak basah oleh hujan.

▸
5

Kembali Otomatis

Ketika sensor tidak lagi mendeteksi hujan, jemuran dikembalikan ke posisi semula secara otomatis.

06Opsional

Coding Program

Cuplikan kode program Arduino.

jemuran_otomatis.ino
#include <Servo.h>

// ==== Konfigurasi Pin ====
const int pinSensorHujan = A0;   // Pin analog sensor hujan (AO)
const int pinServo       = 9;    // Pin sinyal motor servo

// ==== Konfigurasi Posisi Servo ====
const int posisiKeluar = 90;   // posisi jemuran di luar (cerah)
const int posisiMasuk  = 0;    // posisi jemuran ditarik masuk (hujan)

// ==== Ambang Batas Sensor ====
// Semakin kecil nilai analog, semakin basah sensornya.
// Sesuaikan nilai ini setelah kalibrasi di tempatmu.
const int ambangBatasHujan = 500;

Servo servoJemuran;
bool statusHujanSebelumnya = false;

void setup() {
  Serial.begin(9600);
  servoJemuran.attach(pinServo);
  servoJemuran.write(posisiKeluar);  // posisi awal: jemuran di luar
}

void loop() {
  int nilaiSensor = analogRead(pinSensorHujan);
  bool hujanTerdeteksi = (nilaiSensor < ambangBatasHujan);

  Serial.print("Nilai Sensor: ");
  Serial.println(nilaiSensor);

  if (hujanTerdeteksi && !statusHujanSebelumnya) {
    Serial.println("Hujan terdeteksi! Menarik jemuran masuk...");
    servoJemuran.write(posisiMasuk);
    statusHujanSebelumnya = true;
  }
  else if (!hujanTerdeteksi && statusHujanSebelumnya) {
    Serial.println("Cuaca cerah. Jemuran dikembalikan ke luar...");
    servoJemuran.write(posisiKeluar);
    statusHujanSebelumnya = false;
  }

  delay(500); // jeda pembacaan sensor
}
